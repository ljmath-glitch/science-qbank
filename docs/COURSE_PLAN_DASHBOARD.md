# 課程規劃儀表板（course-plan.html）規格

目的：讓老師（及補習班主任）能「從題庫系統即時」看到學測地科的命題趨勢，並依趨勢排 9 堂課，
每堂課的課前考／作業題直接從題庫挑。所有數字都來自題庫，不手寫。

## 1. 資料來源（只讀，注意 Supabase 流量）
- 專案同其他頁面：`SUPABASE_URL` / `SUPABASE_ANON_KEY`（見 analytics.html 頂端）。
- 只抓需要的欄位，**不要抓 q / sol / imgs（含 base64，流量大）**：
  `id, exam, no, type, unit, sub, kp, step, mem, con, chart, group_id, ans, summary, field, book`
  條件：`field='地科'` 且 (`exam like '%學測'` 或 `exam like '%北模%'`)；`type='passage'` 的列（題組文章）不算題數，但可用來知道哪些 group_id 是題組。
- 分頁抓取（每次 1000 筆，同 index.html `load()`），結果存 `sessionStorage`（key `cp_questions_v1`，附時間戳，10 分鐘內重用），並提供「重新載入」按鈕。
- 題庫目前學測地科：111~115 年共 83 題（不含 passage）。**北模考題尚未入庫**；儀表板必須在「有北模資料就顯示、沒有就顯示『尚未入庫』」的前提下正常運作，北模 exam 命名建議 `114北模E2` 之類（`exam like '%北模%'`），年度取前 3 碼。

## 2. 章節對應層（最重要的邏輯，集中成一個可測試的函式 `mapHanlinUnit(q)`）
題庫標籤是龍騰版（第一~七章），授課用翰林版 7 單元。以 `sub` 與 `kp`（課綱內容代碼）為準，規則依序判斷（先中先贏）：

```
sub 以 1-1 → 一-1 地球的起源
sub 以 1-2 → 一-2 地理環境的演化
sub 以 1-3 → 一-3 探索地球歷史的方法
sub 以 2-1，或 kp 含 EFa-Ⅴc-1 → 三-1 地球內部構造與組成
sub 以 2-2 → 三-2 板塊運動
sub 以 2-3 → 三-3 地震
kp 含 EEd-Ⅴc-1 → 二-3 銀河系與宇宙
sub 以 5- 且 kp 含 EEd-Ⅴc-2 或 EEd-Ⅴc-4 → 二-4 恆星的性質
sub 以 5- 且 kp 含 EEd-Ⅴc-3 → 二-6 多波段觀測
sub 以 5-2 → 二-5 從地球看星空
sub 以 5-1 → 二-1/2 太陽系與地球的多重屏障
sub 以 5-3 → 二-3 銀河系與宇宙
sub 以 3-1 → 五-1 大氣的組成與結構
sub 以 3-2 且 kp 含 EIb-Ⅴc-4 → 五-4 垂直運動與天氣變化
sub 以 3-2 → 五-2 空氣中的水氣
sub 以 3-3 → 五-3 大氣的水平運動
sub 以 3-4 → 五-5 氣象預報（天氣圖）
sub 以 3-5 → 五-6 氣象災害（颱風與洪水）
sub 以 4-1 → 四-1 海洋的成分與結構
sub 以 4-2 → 四-2 海水運動
sub 以 4-3 → 六-2 短期氣候變遷（聖嬰）
sub 以 6-1 → 六-1 氣候的變遷
sub 以 7- 或 kp 含 ENa-Ⅴc-2 → 七 地球資源與永續發展
sub 以 6-（其餘 6-2、6-3） → 六-3 氣候變遷對環境的影響
其他 → 「未分類」並在畫面角落列出數量，點開可看是哪幾題
```
- 對應規則放在檔案最上方的 `HANLIN_RULES` 陣列（`{test:(q)=>bool, unit:'三-2'}`），並提供「單題手動覆寫」：覆寫表存在 `syllabus_doc` id=5 的 JSON（`{overrides:{題目id:'三-2'}, plan:{...}}`，讀寫方式同 syllabus_doc id=4）。
- 翰林 7 大單元：一 探索地球、二 天文、三 地質、四 海洋、五 大氣、六 氣候變遷、七 地球資源與永續發展。

## 3. 畫面（單頁，白底、品牌深紅 #850103，沿用 analytics.html 的樣式與頁首「重新整理」鈕；手機也要能看）
頁首：標題「學測地科・課程規劃儀表板」＋資料範圍篩選（學測／北模／全部、年度區間，預設近 5 年學測）。

**分頁 A「命題趨勢」**
1. KPI 列：總題數、年數、題組比例、有圖表比例、近 3 年平均每年題數。
2. 「單元 × 年度」熱度表（行＝7 單元＋小節可展開，列＝111…115，格子顯示題數，色階深淺）；末兩欄：5 年總占比、近 3 年占比、趨勢箭頭（近 3 年占比 − 前 2 年占比，±3 個百分點以上顯示 ↑／↓）。
3. 堆疊長條圖：每年各單元題數占比（純 SVG／CSS，不要引入大型圖表函式庫；可用 Chart.js CDN 固定版本也行，但優先純 SVG）。
4. 題型與圖表趨勢：每年 A2 概念推論／B2 圖表推論／E2 素養／非選（填、計、D2）的占比；有表格／函數圖／等值線圖的占比；平均難度（step+mem+con）與「高難度（≥7）題數」。
5. 「近年新增熱點」列表：近 3 年出現但前 2 年少見的小節（例如多波段觀測、地震、氣候的變遷），與「近年消退」列表。
6. 若有北模資料：同樣的熱度表再加一欄「北模占比」，讓老師對照模擬考與正式考的落差。

**分頁 B「9 堂課計畫」**
- 內建預設 9 堂規劃（可在畫面上編輯，存回 `syllabus_doc` id=5 的 `plan`）。每堂含：堂次、日期（預設顯示「待確認」，可點選輸入日期）、主題、對應單元清單與各單元分鐘數（講解合計 85 分鐘）、對應影片備註（文字欄）。預設資料：
  1. 開課與趨勢 10；一-1/一-2 起源與演化 20；一-3 探索歷史方法（定年）30；二-1/2 太陽系與多重屏障 25
  2. 二-3 銀河系與宇宙 15；二-4 恆星性質 40；二-6 多波段觀測 30
  3. 二-5 天球、周日、周年運動 60；二-5 月相與日月食 10；二 天文統整演練 15
  4. 三-1 內部構造與地震波 25；三-2 板塊運動、斷層、火山帶與火成岩、台灣板塊 60
  5. 三-3 地震 50；三-4 山崩土石流 5；四-1 海洋成分與結構 30
  6. 五-1 大氣組成 15；五-2 水氣與濕度 25；五-4 垂直運動與天氣變化 25；五-3 水平運動與科氏力 20
  7. 五-5 天氣圖與台灣天氣 25；五-6 颱風與洪水 40；四-2 海水運動（前半：風成流、黑潮、台灣洋流）20
  8. 四-2 潮汐與波浪 35；六-2 聖嬰與反聖嬰 25；六-1 氣候的變遷 25
  9. 六-3 氣候環境影響與人類活動 25；七 資源與永續 15；跨單元綜合演練與歷屆試題（含 115 年）45
- 每堂卡片自動計算並顯示：該堂涵蓋單元在題庫的歷屆題數（學測／北模）、近 3 年題數、「時間占比 vs 命題占比」差異提示（時間占比比命題占比高／低 8 個百分點以上標色提醒）。
- 頁尾總覽：各單元「建議講解分鐘 vs 5 年命題占比 vs 近 3 年命題占比」對照表。
- 每堂 150 分鐘固定流程（課前考檢討 20、作業檢討 20、講解 85 含休息 10、演練與作業說明 15）顯示在頂端說明。

**分頁 C「題目池（課前考／作業）」**
- 選一堂課 → 列出該堂涵蓋單元的題庫題目（來源可切換：學測／北模／全部；可依年度、題型、有無圖表篩選），顯示：年度、題號、單元、題型、難度、題幹摘要（`summary`）。
- 每題可勾選；按鈕「加入選題並到組卷」：把勾選的題 id 寫入 index.html 使用的選題機制（查 `PICKS` 的實作與 localStorage／URL 交接方式；若無現成交接，改為把 id 清單存 `localStorage['cp_picks']` 並開啟 `index.html?mode=compose&cp=1`，由 index.html 在載入後讀取並勾選，這一段需一起實作且不破壞現有行為）。
- 同時提供「複製題號清單」按鈕（例如 `114學測#13, 113學測#28 …`）。

**列印／匯出**
- 「列印給主任」按鈕：`@media print` 版型——A4 橫向，頁一為摘要（KPI＋單元趨勢＋9 堂總表，日期欄顯示「待確認」），後續每頁 3 堂；隱藏所有按鈕與篩選。
- 「匯出 CSV」：9 堂計畫表（堂次、日期、主題、單元分鐘、題數）。

## 4. 實作限制與規矩
- 純靜態單檔 `course-plan.html`（HTML/CSS/JS 同檔，無 build），沿用站內字型與配色、`manifest`/PWA 標頭可省略。
- 首頁 `home.html`「題庫出題」區新增入口卡片「課程規劃儀表板」（照其他卡片格式），並在 `guide.html` 新增一小節說明、`changelog.json` 加一筆 entry 並進位 build（見 CLAUDE.md 規矩）。
- 所有 Supabase 查詢只 select 指定欄位；不要寫入題庫 `questions`；唯一寫入是 `syllabus_doc` id=5（覆寫表與課程計畫）。
- 錯誤處理：離線／查詢失敗要顯示可讀訊息與「重試」；題庫沒有符合資料時顯示空狀態。
- 驗證：抽出 `<script>` 跑 `node --check`（CLAUDE.md §10）；把 `mapHanlinUnit` 與統計函式抽成可在 node 測的純函式，寫 `tools/test_course_plan.cjs`，用內嵌的少量假資料驗證對應規則、占比計算與趨勢箭頭；實際資料驗證：用 curl 或 supabase 腳本無法時，至少用假資料跑通。無法在瀏覽器驗證的部分要在回報中明說。
