## 版面特徵（從 PDF 與 XML 觀察）
- 舊樣本可能含浮動定位圖片；這不是 ZZExam 的輸出規格。ZZExam／網頁預覽一律使用與文字排列的 inline 圖片，不做文繞圖。本文件只可作紙張、邊界與字型參考。
- 沒有使用表格；選項靠 Tab 定位對齊：依選項長度自動用一行四欄（A B C D 並排）、兩欄兩列或直列。
- 每題右下角有來源標籤，例如「[112 中正國中]」，灰色小字、靠右。
- 卷頭：左側閃電 logo、學年學期、「自然科　黃金模擬考」大標、卷別與範圍、年班座號姓名橫線；大題條「一、單選題　／每題2分，共80分」（左側黑色粗條＋底線）。
- 頁首（第2頁起）與頁尾：「TZU TZU」、頁碼「— 2 —」、科目；右下浮水印（ABK）。
- 公式多為斜體文字＋上下標或圖片，Word 中沒有 OMML（oMath 0）也沒有 OLE（0 個）。
- 題號格式：「1.(　)」答案括號在題號後。

## 對匯出與預覽的要求
1. 預覽畫布與 Word 使用同一組紙張、邊界、欄數、字型、字級（上表）。
2. 文繞圖（靠右）要在預覽與 Word 兩邊都支援，並以 cm 儲存圖寬高與距離。
3. 選項排法規則（按最長選項寬度決定一行四欄／兩欄／直列）要寫成規則，預覽與 Word 共用。
4. 來源標籤、題號括號、大題條、頁首頁尾都屬於版面規格的一部分。
