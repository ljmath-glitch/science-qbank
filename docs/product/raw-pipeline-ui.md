# raw.html「考卷匯入工作單」拼圖式流程介面（需求規格）

使用者原話：這個介面太醜；要**動態互動式 UI**，**一次看到全部**；要有**進度條**；**每一步都是一塊拼圖**，**每完成一個要看得出來**；要顯示**運行時間與秒數**。

## 版面
- 頁首一條「流程拼圖盤」：八塊拼圖依序排成一列（桌機）／兩列（平板）／可橫向滑動（手機）。
  1 清除筆跡 → 2 自動命名 → 3 OCR → 4 題庫 Excel → 5 手動切圖 → 6 詳解 → 7 詳解 Excel → 8 回題庫
- 拼圖外形用 SVG／CSS 畫出凹凸卡榫（相鄰兩塊互相嵌合），不依賴圖片或外部套件。
- 盤面上方：整份考卷的總進度條（完成幾/8 步＋百分比）與「總運行時間」。

## 每塊拼圖要顯示
| 狀態 | 外觀 |
|---|---|
| 等待 | 灰色虛線外框，淡色 |
| 進行中 | 品牌紅外框＋流動動畫的進度條、百分比、**即時計時（mm:ss，每秒更新）**、目前子步驟文字（例：第 3/5 頁・清除筆跡） |
| 完成 | 填滿品牌綠，✓ 動畫，拼圖「卡榫嵌合」的小動畫（約 400ms）＋**最終耗時**（例：用時 52.3 秒）＋一行小成果（清稿頁數、辨識題數、Excel 筆數、裁出圖數…） |
| 失敗 | 紅色，顯示簡短原因與「重試」鈕 |
| 略過 | 淡藍，標示「已略過」（例如使用者直接丟乾淨 PDF，跳過步驟 1） |

- 點任一塊拼圖 → 頁面平滑捲到並展開該步的詳細操作區（原本各步驟的內容區塊），不跳頁、不離開 raw。
- 已完成的拼圖可點擊回看成果（縮圖、下載連結）。
- 全部完成時：整盤拼圖合成一張，顯示「全部完成・總用時 X 分 Y 秒」與「回題庫匯入」大按鈕。

## 資料與狀態
- 以單一狀態物件 `PIPE = {steps:[{id,label,state,pct,startedAt,elapsedMs,detail,summary}], startedAt}` 驅動畫面；各步驟既有函式（startDehand、runAutoOcr、ocrMakeCsv、…）只呼叫 `pipeStart(id)`、`pipeProgress(id,pct,detail)`、`pipeDone(id,summary)`、`pipeFail(id,msg)`、`pipeSkip(id)`，不要把畫面邏輯混進業務邏輯。
- 計時器用單一 `setInterval(1000)`，頁籤隱藏時以時間戳補算，不要累積誤差。
- 重新整理頁面要保留各步驟狀態摘要（sessionStorage），已完成的顯示「上次結果」。

## 不可破壞
- 既有各步驟的功能、`dehandResult`、`OCR_PDF_FILE`、`setCropFile`、裁圖／批次貼圖／匯入題庫流程。
- 手機寬度（375px）無橫向捲動（拼圖盤自己的橫向滑動除外）。
- 淺色／深色模式皆可讀。

## 驗收
1. 用 `.tmp_dehand_test/s.pdf` 實跑：步驟 1 進行中時看得到進度條與秒數、完成時拼圖嵌合動畫與耗時。
2. 模擬失敗（斷開 OCR 主機）：該塊變紅、可重試，其他塊不受影響。
3. 桌機與 375px 寬度截圖。
