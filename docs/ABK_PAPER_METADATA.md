# ABK 卷頭資料

在預覽工具列或「匯出設定 → 基本設定」均可修改考卷標題、A／B／K 卷種、冊次、章節範圍。編號欄唯讀。

- 冊次：JB1～JB6。標題寫「第三冊」或「JB3」時自動推斷；選題冊次與章節作初始值。
- 範圍：`CH1+CH2`、`1-1+1-2`、`第1章+第2章` 均可，統一為 `CH1+CH2` 或 `CH1-1+CH1-2`。
- 範例：第三冊＋CH1+CH2＋A 卷 → `SCI-JB3-CH1+CH2-A`。
- 考卷標題只決定標頭題名，不用年級字串當作冊次，不用學校考卷來源當作章節。
- 修改只更新目前考卷欄位，不修改題庫題目的冊次／章節。
- Word 匯出之前驗證標題、冊次、卷種、範圍，無效時停止，不輸出帶有占位提示的編號。
- 首頁與續頁的原生 Word 頁首，包括 DrawingML／VML fallback 中分散的文字 run，均替換同一編號。保留各 run 格式、幾何、圖形及 watermark 關係。

回歸：`tools/test_paper_metadata.cjs`（需要本機 HTTP 服務）涵蓋 WebKit／Chromium、兩套控制項同步、標題冊次推斷、預覽與實際 DOCX 的編號、課前考單欄匯出與無效章節攔截。
