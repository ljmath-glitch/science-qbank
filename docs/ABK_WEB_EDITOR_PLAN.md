# ABK 網頁編輯與輸出一致性

目標：網頁完成大部分考卷編輯；整頁預覽和 PDF 共用版面；Word 繼續保留原模板與可編輯的原生編號，供少量最後修整。不要宣稱瀏覽器與 Word／MathType 的分頁可以保證完全相同。

## 已建立的第一階段

- `paper-output.js` 使用現有完整考卷分頁，供 ABK 題目卷的匯出設定預覽與專用列印視窗共同使用。
- 不再以題數／字數估算 ABK 題目卷設定預覽；以載入字型、圖片、公式後的實際排版產生各頁。
- 列印頁保留文字、公式、圖片及浮水印，不把整頁變成一張低解析度截圖，也不列印題庫工具列或編輯按鈕。
- 固定 B4 紙張尺寸，窄視窗不改變輸出版面；超出紙張、圖片載入失敗、輸出途中設定變更時報錯，不能默默裁切或混用內容。
- 修正 ABK 頁碼被通用圖層規則改成相對定位的問題。
- 不修改已確認的 `templates/abk_tpl.docx`。
- `paper-metadata.js` 統一預覽工具列／匯出設定的標題、A/B/K、冊次與章節，輸出編號 `SCI-JB3-CH1+CH2-A`。標題中有冊次會帶入選單；修改冊次會同步標題內既有冊次文字。Word 首頁／續頁僅替換編號文字，原生版面與浮水印不變。
- `paper-layout.css` 用 Word 模板的 48 px 頁邊、47.27 px 欄距、10 pt 正文、題號尺規位置、6 pt 段後空間、手填配分、11.02 cm 題組框及 270×135 px 等比例隨文圖上限。圖片不再用自由拖曳位置或百分比撐滿欄位。
- 編輯畫面採固定 B4 紙張，再等比縮放，單一文件捲軸；工具列不參與捲動，下方題庫浮動按鈕在預覽中隱藏。
- 回歸：`tools/test_paper_output.cjs` 涵蓋 WebKit／Chromium、26 題分頁、直／橫圖比例、公式、浮水印、無控制項、窄視窗和超長題目。`--pdf` 可產生 QA 用的瀏覽器 PDF。

## 目前界線

- 新流程支援 ABK／課前考題目卷（含原有題內答案模式）；同時勾解析卷時，題目預覽仍使用實際整頁，解析卷則另外用版型示意並明確標示非 Word 分頁。
- 「儲存 PDF」開啟專用題目卷的瀏覽器列印對話框，使用者選擇儲存成 PDF；不等於直接下載 PDF 檔。沒有新增後端轉檔服務。
- 編輯歷史仍依賴舊 DOM 機制；超長單題／單篇文章尚不支援原生跨欄延續，會停止輸出提示，不能默默裁切。不能把此次工作当作完整所見即所得編輯器已完成。
- Word 範本路徑 `_tplQuestionText` 仍移除 rich marks，網頁局部字級／粗體等尚未完整同步到模板 Word。

## 下一階段驗收

1. **文件資料統一**：考卷副本的富文字、字級、段落、圖片尺寸、題組、標頭欄位與排序可還原，撤銷／重做不依赖已被重繪移除的 DOM 節點；明確區分改考卷與改題庫原題。
2. **ABK 規格一致**：採用 ABK skill 的段落、尺規、內建題號與手填配分空格；圖片同一組等比例尺寸供網頁／PDF／Word 消費。正文一题一段、選項軟換行且標籤後無空格。
3. **編輯即版面**：固定紙張畫布，只等比縮放；字級／圖尺寸改變後重新分頁但不亂序；長題／長文章可延續到下一欄／下一頁，不丟內容，維持游標與選取。
4. **PDF 完成度**：題目卷和解析卷皆使用同一輸出來源，提供明確的直接下載或原生列印方式；檢查字型、公式、跨頁與可搜尋文字。若選擇後端轉檔，另確認部署、成本、題目資料與字型授權。
5. **Word 最後修整**：保留 native lists、題組文字方塊、字型／段落及局部格式；LaTeX 仍保留供 MathType 轉換。接受公式轉換與不同排版引擎造成的小幅分頁差異。
