## 1. 操作教學影片＋動圖（最優先）

- **目的**：讓其他老師、工讀生不看文字說明也能操作。
- **範圍（第一批）**：
  1. 考卷前處理（以「簡單模式」為主，補充自動匯題的人工檢驗）
  2. 出題精靈（組卷精靈）
- **第二批（另外拍）**：題庫管理、考卷進度（共編進度表）。
- **做法**：腳本與旁白文字見 `docs/tutorial-video-script.md`，**要先給福大確認腳本**，確認後才製作影片。
- **前提**：等考卷前處理與出題精靈的功能操作都確定、不再大改之後再錄，否則影片很快過時。
- **成品放哪**：影片放在 `guide.html` 對應章節，各步驟旁放 10～30 秒的短動圖。

## 2. AI 出相似題

- **需求**：從題庫撈現有題目，讓 AI 產生相似題型（換數字、換情境、同知識點），老師審核後存回題庫。
- **參考**：其他補教題庫系統已有此功能（見 2026-11-13 對話的比較）。
- **要先決定**：
  - 用哪個 AI（Claude／Gemini／ChatGPT／本機），費用算誰的 API 金鑰。
  - 只開放管理員，還是所有老師都能用（目前 AI 功能一律收在「管理員」密碼區）。
  - 生成的題目一定要經人工審核才進題庫，並標記「AI 生成」來源。
- **入口建議**：題庫管理的題目卡片「產生相似題」、組卷精靈選題時「補相似題」。

## 3. 人工檢驗頁再加強

- 點右側題目卡片，左側清稿自動捲到該題位置（OCR 主機有每行文字座標，可用來定位）。
- 重新整理頁面後，從雲端讀回已存的原卷／清稿（前處理已會存到雲端），不必重丟考卷。
- 卡片上直接刪圖、改成題組共用圖（目前要在左側清稿的框上改）。

## 4. 自動切圖在公司主機實測

- 2026-11-13 已把自動切圖改成背景工作＋輪詢（science-qbank #67、exam-answer-key-formatter #11），尚未在公司主機與手機實際跑過完整考卷。
- 若仍失敗：看前處理「時間紀錄」裡的失敗原因；可能是主機第一次下載版面模型（modelscope.cn）失敗。

## 5. 待評估（還沒決定要不要做）

- **手寫塗改兩版並列**：學生在考卷上把答案或題目塗改過時，系統把「清除筆跡前」與「清除筆跡後」兩個版本並排，讓老師挑要用哪個。目前只有清除筆跡＋橡皮擦。
- **學生端錯題本／排行榜**：需先決定補習班要不要做學生端（目前只有每日一題）。
