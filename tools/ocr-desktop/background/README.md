# ZiziOCR 本機程式：背景執行（沒有黑視窗）

ZiziOCR 本機程式 1.0.2 原本是一個黑色命令提示字元視窗，必須一直開著，關掉就不能用。
這個小工具讓它改成**隱藏在背景執行**，登入電腦後自動啟動，不會被誤關。

## 使用
1. 先照常下載並解壓縮 ZiziOCR（匯卷頁選「本機」→「下載本機程式」）。
2. 把本資料夾三個檔案（`ZiziOCR背景執行.bat`、`install-background.ps1`、`停止ZiziOCR.bat`）放在同一個資料夾，雙擊 **`ZiziOCR背景執行.bat`**。
3. 它會自動找 `ZiziOCR.exe`（找不到會請你把 exe 拖進視窗）、關掉原本有黑視窗的那個、改用隱藏方式啟動。
4. 回題庫網頁，「OCR 運算主機」選「本機」，按「測試連線」。

## 停止
雙擊 **`停止ZiziOCR.bat`**（會停止程式並取消登入自動啟動）。

## 限制
- 這是「隱藏視窗」，沒有右下角圖示，所以看不到狀態；要確認有沒有在跑，網頁按「測試連線」即可。
- 想要右下角有小圖示、可看狀態、可讓別人連線的版本，請改裝「主機電腦安裝包」（匯卷頁「下載主機安裝包」）。
- Windows 實機尚未驗證。
